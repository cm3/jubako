作例の概要構築する変更する仕組み検証と共有USB版の使い方

構築する — レシピからISO・USB起動まで

Debian 13・amd64の構築ホスト、ネットワーク、十分なディスク空き、sudoを使えるアカウントを用意します。WSL2のDebianでも構築設定を準備できます。起動・GPU・キーボードの動作はVMや実機で確認します。

1. 構築ツールを入れる

sudo apt update
sudo apt install live-build debootstrap xorriso squashfs-tools \
  dosfstools mtools syslinux-utils zstd python3 git

sudoはホストへのパッケージ導入と、ビルド時のchroot・一時マウントに使います。USB書き込みは後の別操作です。ISOのほかに展開済みOSとキャッシュを置くため、20GB以上を空き容量の出発点として、実際の使用量を確認してください。追加するアプリによって必要量は増えます。

2. ソースと依存を確認する

git clone https://github.com/cm3/jubako.git
cd jubako
bash scripts/check.sh
bash scripts/check.sh --dependencies

通常の検査はshell・XML・説明書のリンク・構成条件を確認します。依存検査はDebianの対象APT索引を build/ へ取得して解決を模擬します。ホストのAPT設定を変更せず、パッケージ導入やUSB操作も行いません。

3. 新しい作業先を準備して構築する

bash scripts/prepare.sh
sudo bash scripts/build.sh

prepare はレシピを build/runs/ の新しいディレクトリへコピーして設定を生成します。build はそこでISOを作ります。成功すると live-image-amd64.hybrid.iso と SHA256SUMS の場所が表示されます。ログは同じrunの logs/build.log です。

設定を変更した場合やビルドが失敗した場合は、レシピを修正して再度 prepare し、新しいrunで構築します。この作例には、古いrunからの高速再利用や自動削除の機能はありません。

4. ISOを起動する

まずVMの起動媒体としてISOを指定するか、Rufusなどで自分のUSBへ書き込みます。書き込むUSBの既存データは消えます。対象・容量と退避済みデータを確認してから実行してください。このリポジトリのスクリプトはUSBの選択や書き込みを行いません。

Secure Bootの動作は、UEFI/Secure Boot対応のVMまたは実PCで確認します。BIOSのVMで起動できることとは別の結果です。

5. デスクトップを使う

  • Win+Enter：端末。
  • デスクトップの右クリック：Firefox・Wi-Fi・音量・入力設定のメニュー。
  • Win+Escape：GUI終了。再度起動するにはCUIで start-desktop。

日本語入力のオン・オフと変換、Firefox、Wi-Fi、音声を対象PCで試します。GUIが出ない場合は ~/.cache/ja-live/desktop.log を確認してください。

RAMセッションのため、Wi-Fi・認証・アプリ設定は再起動で消えます。残す作業ファイルは別の保存媒体へ明示的に保存します。

jubako — 自分の日本語Debian Liveを作る

必要なアプリと設定を選び、USBから起動する自分の作業環境へ。

このrepoはDebianのlive-buildを使う小さな作例です。labwc、Firefox、端末、fcitx5/Mozcを組み合わせ、GUIの日本語表示・入力を最初の目標にします。完成したOSの配布ではなく、レシピを読んで変更するための出発点です。

初回ドラフト。この切り出した例のフルビルドと起動はまだ未確認です。元の個人用jubakoでの成功と区別しています。

まず動く作例へ

標準の単一ISOを作ります。3区画や暗号化を最初から必須にせず、問題を切り分けやすくします。

どこを変えるか分かる

アプリ一覧、起動設定、キー、メニューはそれぞれ小さなファイル。巨大な設定基盤を覚える必要はありません。

自分で構築する

個人の設定・認証を配布物へ混ぜず、Debianから必要なパッケージを取得して組み立てます。

最初に読む順番

  1. 構築ツールを入れ、ISOを作る。
  2. レシピの変更点を把握する。
  3. LiveとRAM、GUI、署名起動を理解する。
  4. 検証範囲と公開時の確認事項を読む。

Debianから始める理由

必要な部品を少しずつ足す構築には、live-buildの標準レシピとDebianパッケージの組合せが扱いやすいためです。Ubuntu/Xubuntuでも類似の環境は作れます。Xubuntuの完成したデスクトップを少し変える用途とは、出発点が違います。

最初はDebian 13・amd64だけを対象とし、Intel向けfirmwareを例示します。ARM、すべてのGPU/Wi-Fi、複数の構築ホストを一度に保証する方針ではありません。

これからの候補

個人状態と作業ファイルを分ける3区画、LUKS保存、OSの3層と高速更新、ZedやAIを使うプロフィールは、最初の例が独立して動いた後に追加する候補です。現在収録している機能として案内しません。

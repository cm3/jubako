jubako — 自分の日本語Live USBを作る

Debianのパッケージから、必要なアプリと設定を選んで作る。

このリポジトリは、Debian 13のlive-buildで日本語GUI付きのLive ISOを構築する作例です。Linuxの基本操作ができ、自分のUSBで使う環境を作りたい人向けに、編集箇所と構築手順をまとめています。

小さなデスクトップ

labwc、Firefox ESR、Xfce Terminalを組み合わせます。日本語入力はfcitx5＋Mozc、キーボードはJIS配列です。

見通せるレシピ

パッケージ一覧、キー、メニュー、起動処理はそれぞれ独立したファイルです。変更をレシピに残して再構築できます。

標準ISOから始める

署名済みの起動経路とRAMセッションを使います。最初は永続保存を追加せず、アプリと機器の動作を確認します。

作れるもの

amd64用のLive ISOです。UEFI/Secure Bootを有効にした構成で、VMまたは自分で用意したUSBから起動します。Wi-Fiと音量の設定画面、日本語フォントと入力方式を収録します。

この作例はRAMで動き、再起動後にアプリ設定やWi-Fiを残しません。保存する作業は別媒体へ書き出します。3区画の暗号化USB、Zed、AI機能を備えたjubakoの使い方はUSB版の説明書にありますが、このリポジトリのレシピとは収録範囲が異なります。

始める

  1. 構築ホストを準備してISOを作る。
  2. 使うアプリ・firmware・キーを変更する。
  3. 起動とRAMセッションの仕組みを理解する。
  4. 実機で検証し、自分の変更を共有する。

検証済みの範囲はソース検査、Debian依存解決のシミュレーション、構築設定の生成です。この公開レシピのISOビルドと起動は未確認です。対象機器で確認する項目は検証と共有にまとめています。

Debianを使う理由

live-buildの標準構成を使い、Debianパッケージを必要な順に追加できるためです。完成したデスクトップ環境を改造するより、部品を選んで構成を把握したい場合に適した出発点です。

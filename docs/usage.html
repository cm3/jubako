jubako — USB版の使い方

AIと書く、持ち運べる日本語Linux。

Debian Liveをもとに、ブラウザ・端末・Zed・日本語入力を組み合わせたUSBの作業環境です。USBから起動し、プロジェクトと必要な設定を持ち歩いて使います。

このページは、暗号化保存・Zed・AIに対応したjubako USB版の説明書です。このリポジトリの小さな構築作例は、標準ISO・RAM環境から始める別の範囲で、ここに書いた暗号化保存・Zed・AI機能をすべて収録しているわけではありません。完成したUSBイメージの配布は行っていません。

起動する

  1. USBを挿し、PCの起動メニューでUSBを選びます。Secure Bootを有効にしたまま使う構成です。機種のGPU・Wi-Fi対応は収録firmwareによります。
  2. 保存領域の案内で u を選び、LUKSパスフレーズを入力します。解錠した設定・Wi-Fiプロファイルを準備してから、labwcデスクトップに入ります。
  3. 保存状態を使わずに試すときは r を選びます。この起動の認証・設定・会話はRAMだけに残り、再起動で消えます。途中で保存先を切り替えず、解錠して使うには再起動します。

OSは通常ユーザーで自動ログインします。LUKSの解錠後、保存された認証を使えるので、解錠済みのPCを共有する場合は扱いに注意してください。サスペンドは暗号化保存領域を閉じません。

普段の操作

操作使い方
ブラウザ・Zed・端末タスクバー左の固定アイコンから開きます。ブラウザを閉じてもデスクトップは動き続けます。
端末Win+Enter。Xfce Terminalが開きます。コピーは Ctrl+Shift+C、貼り付けは Ctrl+Shift+V。
日本語入力GUIはfcitx5＋Mozc。変換・無変換キーで切り替えます。設定は jubako-util のJapanese input settings。
プロジェクトZedのアイコンでREADME付き一覧を開きます。「新規作成」でREADMEを作って開き、「削除」でUSBのゴミ箱へ移します。開いているプロジェクトは削除できません。
Wi-FiトレイのWi-Fiから接続します。解錠していると接続情報が保存され、次回の起動で自動接続します。明示的な削除は jubako-util。
音量・明るさFnキーで変更すると画面に値が出ます。音量はタスクバーのホイールでも変更でき、クリックで消音、右クリックで詳細設定です。
スクリーンショットWin+Shift+S で範囲、Win+S で全画面。クリップボードとUSBのScreenshotsへ保存します。
電源右下の電源アイコンで、サスペンド・再起動・終了・自動スリープの時間を選びます。
ユーティリティー端末で jubako-util。メニューは英語で、素のコンソールでも読めます。全コマンドは jubako-commands、またはコマンド一覧。

AIを使う

ZedではAgentパネル、端末ではCodex CLIを使えます。認証は利用時に行い、構築レシピや起動イメージへ個人の認証情報を入れません。

jubako-codex start
jubako-codex status

start は必要ならログインを案内し、対話モードを開きます。jubako-codex login では、スマートフォンから開く認証ページをQRで表示できます。通信にはWi-Fiなどの接続が必要です。

何がどこへ保存されるか

場所内容再起動後
FAT32 / JUBAKO_BOOT署名済み起動ファイルとOS。OSはbase・apps・customの3層SquashFS。残ります。通常のUSB更新で入れ替える領域です。
LUKS2＋ext4 / JUBAKO_DATAWi-Fi、Codex/ClaudeのCLI認証と会話、Zed設定、Mozc学習など。解錠して使った場合は残ります。
exFAT / JUBAKO_WORKプロジェクト、文書、スクリーンショット、診断ログ。Windowsなどから読めます。残ります。暗号化されていません。
RAM実行中のOS変更、ブラウザのプロファイルとCookie、一時ログ、セッションkeyring。消えます。RAM起動の認証・会話・設定も保存されません。

3つの区画と、OS内部の3層は別の構造です。OS更新はFAT32だけを入れ替え、ext4/exFATのデータを保ちます。使用するUSBは、この構成に合わせて自分で準備したものを使います。

プロジェクトはexFATの debian-live 以下にあります。暗号化ext4を閉じても、exFATの文書やログは保護されません。保存済みAI認証の削除は jubako-auth-forget。設定・会話は残します。

困ったとき

GUIが起動しない・コンソールへ戻りたい

起動失敗はコンソールへ戻り、終了コードとログの場所を表示します。端末で jubako-commands を読むと、利用できる操作が分かります。

Ctrl+Alt+F1〜F6 はLinuxの仮想端末を切り替えます。GUI終了は Win+Escape または jubako-gui-exit。日本語表示コンソール（kmscon）を開いた後は exit または Ctrl+D で実VTへ戻り、jubako-desktop でGUIに入り直せます。

CUIは日本語表示と英語入力に対応する構成です。日本語変換入力はGUIで使います。

音が出ない

音量の詳細設定の「構成」タブで、スピーカー・ヘッドホン・外部画面の出力先を確認します。イヤホンを抜いても検知が残ることがあり、Speakerを含むプロファイルへの切替で戻った事例があります。

jubako-diag audio silent
jubako-diag audio working

無音のときと復旧後を比べて診断を残せます。

診断を持ち帰る
jubako-diag save

必要な権限のためsudoを使い、exFATの debian-live/logs/ へ保存します。通常の診断には認証・会話・全環境変数を含めません。過去の試験資料はUSB内の zed-test/docs/ から読みます。

USB-Cのドライバーを再読み込みする jubako-diag usb-c は、必要な場合だけ機器をすべて外して実行してください。

異常時にRAM側のAIデータを残す

Zed・Codex・Claudeを閉じ、別の端末で：

jubako-util ram-backup

exFATの debian-live/recovery/ にtarとチェックサムを保存します。元データは変更せず、自動統合もしません。これは認証・私的な会話を含み得る暗号化されていない退避です。公開せずに保管し、必要に応じて個別に復旧します。

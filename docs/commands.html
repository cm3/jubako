USB版の使い方 ／ 構築作例のトップ

コマンド一覧

この一覧はjubako USB版の説明です。公開リポジトリの小さな構築作例とは収録範囲が異なります。

jubako に入っている自前のコマンドです。端末で名前を打って使います。端末では jubako-commands で同じ一覧（英語）を、jubako-util でよく使う操作のメニューを出せます。sudo と書いたものは管理者の権限を使います（保存領域の解錠ではLUKSパスフレーズを入力します）。

普段使うもの

コマンドできること
jubako-utilよく使う操作のメニュー。日本語入力の設定、スクロール方向、保存済み Wi-Fi の削除、AI の認証の削除、非常用の書き出し、コマンド一覧。GUI の外（コンソール）では、Wi-Fi の設定や日本語のコンソールなど、コンソール用の項目になる。
jubako-commandsコマンドの一覧を端末に出す（英語。素のコンソールでも読めるように）。
jubako-zedZed でプロジェクトを開く。README の冒頭を見ながら選べる画面が出る。新規作成・削除もここから。開いているプロジェクトは重ねて開かず、前面に出す。左のタスクバーの Zed アイコンと同じ。
jubako-terminal端末を開く（Win+Enter と同じ）。
jubako-power電源の画面。操作しないとスリープするまでの時間、サスペンド、再起動、シャットダウン。右下の電源アイコンと同じ。
jubako-screenshot region|fullスクリーンショット。範囲（Win+Shift+S）か全画面（Win+S）。クリップボードに入り、exFAT の Screenshots にも保存される。
jubako-scrollタッチパッドのスクロール方向を切り替える。
jubako-ime-settingsMozc（日本語変換）の設定画面。辞書、予測候補、キー設定。
jubako-codex start|login|qr|status|run端末で Codex を使うための補助。qr はログイン用の URL を QR コードで表示する（スマートフォンでログインするとき）。
jubako-wifi-storage save|restore|forgetWi-Fi の接続情報を ext4 に保存・復元・削除する。接続すると自動で保存されるので、普段は削除のときだけ使う。
jubako-auth-forget保存してある Codex・Claude の認証情報を削除する（設定と会話の履歴は残る）。
jubako-ram-backupext4 が使えず RAM に保存されていたエージェントのデータを、非常用に exFAT の debian-live/recovery/ へtarで書き出す。認証情報を含み得る暗号化されていないファイルなので、非公開で保管する。

デスクトップとコンソール

コマンドできること
jubako-browserGUI（labwc と Firefox）を始める。普段は起動時に自動で動く。
jubako-desktopLinux のコンソールから GUI を始める。
jubako-gui-exitGUI を終える（Win+Escape、右クリックのメニューと同じ）。終わると自動で日本語のコンソール（jubako-console）が開く。
sudo jubako-console日本語を表示できるコンソール（kmscon、tty8）。Ctrl+D で元に戻る。日本語の入力はできない。
sudo jubako-wifiコンソールで Wi-Fi に接続・管理する。

保存領域

コマンドできること
sudo jubako-ext4 unlock|mount|status|close暗号化された ext4（設定・認証・学習の保存先）。unlock はパスフレーズで開く（または RAM だけで使う）、mount はマウントして保存用のフォルダーを準備、status は状態の表示、close は閉じる。普段は GUI を始めるときと起動・終了時に自動で動く。
sudo jubako-exfat mount|status|unmountexFAT（プロジェクトの置き場所）をマウント・確認・取り外しする。

診断

コマンドできること
jubako-diag saveカーネル・システムログ・音声・USB-C などの診断を exFAT の logs に保存する（sudo を使う）。困ったときに、Windows から読める形で持ち帰る。
jubako-diag audio [before|silent|working|after]音声の診断を保存する。音が出ないときは silent、直った後は working を付けると比べやすい。
jubako-diag usb-cUSB-C の電源管理のドライバーを読み込み直してから、診断を保存する。先に USB-C の機器をすべて外す。

自動で動くもの

コマンドできること
jubako-fanCF-SR4 のファンを静かなモードにする（起動時）。
jubako-pana-muteWindows で消音したままでも内蔵スピーカーが鳴るよう、起動時に解除し、終了時に元へ戻す。
jubako-wifi-storeWi-Fi の接続情報の保存・復元（接続時と起動時に自動）。
jubako-input-store入力の設定の保存・復元。

内部の部品（/usr/local/libexec）

上のコマンドやサービスから呼ばれる部品です。直接は使いません。このイメージに収録した部品を分類しています。

GUI のセッション

部品役割呼び出し元
jubako-browser-sessionGUI のセッションの本体。waybar・fcitx5・Firefox などを起動し、終了時に止めるjubako-browser
jubako-panelwaybar を起動し、落ちたら起動し直す（5 回まで）jubako-browser-session
jubako-browser-windowFirefox を開く。開いていれば前面に出す。リンクを開くときにも使うタスクバー、Zed、メニュー、既定のブラウザー
jubako-console-utiljubako-util のコンソール版jubako-util

Zed

部品役割呼び出し元
jubako-zed-pickerプロジェクト選択画面（README の冒頭、新規作成、削除）jubako-zed
jubako-zed-settingsZed の設定に、イメージが管理する項目（ACP など）だけを書き込むjubako-zed
jubako-zed-stateZed の保存先（ext4）を準備するjubako-zed、jubako-zed-uri
jubako-zed-urized:// のリンクを、今の Zed と同じ保存先で開く既定のアプリの設定
jubako-agent-stateCodex・Claude の設定・認証・履歴の保存先（ext4）につなぐjubako-browser-session、jubako-codex、jubako-zed
jubako-login-qrログイン用の URL を QR コードで表示するjubako-codex（login・qr）

保存領域

部品役割呼び出し元
jubako-persist-commonext4 を扱う共通の処理（Wi-Fi・入力の設定・GUI の保存で共有）jubako-persist、jubako-unlock、jubako-wifi-store、jubako-input-store
jubako-unlockLUKS解錠・RAM選択・終了時のclosejubako-ext4、jubako-storage.service
jubako-persist解錠済みext4のmountと保存用ディレクトリ準備jubako-ext4、jubako-unlock、jubako-persist.service

診断

部品役割呼び出し元
jubako-gui-snapshotGUI の状態を、URL や認証を含めずに診断用に書き出すjubako-browser、jubako-audio-diagnose
jubako-audio-snapshot音声の状態を書き出すjubako-gui-snapshot
jubako-audio-kernel音声のカーネル・ハードウェアの情報を読む（設定は変えない）jubako-audio-diagnose
jubako-typec-stateUSB-C の充電の状態を読む（機器のシリアル番号は読まない）jubako-experiment
jubako-gui-diagnosticsroot診断とGUI状態をまとめて保存jubako-diag save / usb-c
jubako-audio-diagnose比較ラベル付きの音声診断jubako-diag audio
jubako-experiment非対話のシステム診断をexFATへ保存jubako-gui-diagnostics
jubako-ppm明示確認後にUCSIドライバーを再読み込みjubako-diag usb-c

USB版の使い方 ／ 構築作例のトップ

コマンド一覧

この一覧はjubako USB版の説明です。公開リポジトリの小さな構築作例とは収録範囲が異なります。

jubako に入っている自前のコマンドです。端末で名前を打って使います。端末では jubako-commands で同じ一覧（英語）を、jubako-util でよく使う操作のメニューを出せます。sudo と書いたものは管理者の権限を使います（保存領域の解錠ではLUKSパスフレーズを入力します）。

LocalSendはGUIの右クリックメニューから、または端末の localsend_app で起動できます。ローカル説明書は file:///usr/share/jubako/docs/usage.html です。

普段使うもの

コマンドできること
jubako-utilよく使う操作のメニュー。日本語入力の設定、スクロール方向、保存済み Wi-Fi の削除、AI の認証の削除、非常用の書き出し、コマンド一覧。GUI の外（コンソール）では、Wi-Fi の設定や文字サイズ変更など、コンソール用の項目になる。
jubako-commandsコマンドの一覧を端末に出す（英語。素のコンソールでも読めるように）。
jubako-zedZed でプロジェクトを開く。README の冒頭を見ながら選べる画面が出る。新規作成・削除もここから。開いているプロジェクトは重ねて開かず、前面に出す。左のタスクバーの Zed アイコンと同じ。
jubako-terminal端末を開く（Win+Enter と同じ）。
jubako-power電源の画面。操作しないとスリープするまでの時間、サスペンド、再起動、シャットダウン。右下の電源アイコンと同じ。
jubako-screenshot region|fullスクリーンショット。範囲（Win+Shift+S）か全画面（Win+S）。クリップボードに入り、exFAT の Screenshots にも保存される。
jubako-scrollタッチパッドのスクロール方向を切り替える。
jubako-ime-settingsMozc（日本語変換）の設定画面。辞書、予測候補、キー設定。
jubako-codex start|login|qr|status|run|network端末版Codexの補助。保存先未準備なら実VTでu/rをやり直せる。qrは認証ページのURLを表示し、networkは認証情報を使わずHTTPSを確認する。qr/networkは保存先未準備でも使える。
jubako-wifi-storage save|restore|forgetWi-Fi の接続情報を ext4 に保存・復元・削除する。接続すると自動で保存されるので、普段は削除のときだけ使う。
jubako-auth-forget保存してある Codex・Claude の認証情報を削除する（設定と会話の履歴は残る）。
jubako-ram-backupext4 が使えず RAM に保存されていたエージェントのデータを、非常用に exFAT の debian-live/recovery/ へtarで書き出す。認証情報を含み得る暗号化されていないファイルなので、非公開で保管する。
jubako-history export ext4|exfat会話JSONLだけを分析用に書き出し・照合する。ext4はlive-user/conversation-exports、exFATはdebian-live/conversations以下。認証・設定・DBは含めない。切替前のRAM記録には --source ram。
jubako-history connect-ext4GUIとエージェントを閉じて実VTで実行。RAM会話をext4へ書き出す／exFATへ書き出す／RAMに残す、を選び、次回Codex起動からext4を使う。元のRAM状態は再起動まで保持する。

別のUSBへ複製する

jubako-util の「Copy this USB」から対象USBとext4の0/1を選べます。RAMモードで起動してGUIを終了し、コンソールのメニューから実行します。直接開くには jubako-util clone。

sudo jubako-clone /dev/disk/by-id/対象USB --ext4 0 は計画表示のみです。--ext4 0 は空の暗号化ext4、--ext4 1 は設定・認証・会話を含む保存済みext4をコピーします。FAT32とexFATのファイルはどちらでもコピーし、exFATだけ複製先の残り容量へ広げます。

書き込みはRAMモードで起動し、GUIと作業アプリを終了してコンソールから実行します。元のexFATは sudo jubako-exfat unmount で外しておきます。計画を確認した後、同じコマンドに --write を追加すると対象USBの全内容を消去する確認が出ます。sudoは区画作成・暗号化・マウント用です。パスフレーズはcryptsetupへ直接入力します。今のRAMの作業内容はコピー対象に含みません。複製先の起動・保存はまだ実機未確認です。

uとrの保存領域

u は暗号化ext4に保存済みの設定・認証・履歴を使います。r は初期構造だけを持つ空のRAM保存領域を作り、同じアプリ用フォルダーを使います。初期構造と既定設定はFAT32上のOSイメージに収録しています。元のext4は開きません。RAM内のログイン・履歴・設定は今回の起動中だけ有効で、終了時に失われます。RAM状態のファイルシステム上限は物理RAMの25%で、必要な分だけメモリを使います。

OS本体をRAMへ全コピーする機能ではないため、rでも起動USBは抜けません。作業ファイルと診断ログは引き続きexFATに保存します。必要なRAM状態は jubako-util ram-backup で手動退避できます。新しい共通RAM領域は ram-store.tar、例外的にホームに残ったエージェント状態は ram-agents.tar になります。共通領域の退避はlive-user以下が対象で、root専用のWi-Fi/入力保存領域は含めません。どちらも認証を含み得る暗号化されていない退避です。

デスクトップとコンソール

コマンドできること
jubako-browserGUI（labwc と Firefox）を始める。普段は起動時に自動で動く。
jubako-desktop --gui元のLinux実VTからGUIを明示起動する。console only起動後も使える。
jubako-gui-exitGUI を終える（Win+Escape、右クリックのメニューと同じ）。元の通常Linuxコンソールへ戻る。
big [16|24|28|32]現在の実VTのフォントサイズを変更する。既定はTerminus Bold 24px。sudoはフォント設定用。GUI端末内では使わない。
sudo jubako-wifiコンソールで Wi-Fi に接続・管理する。

保存領域

コマンドできること
sudo jubako-ext4 unlock|mount|status|close暗号化された ext4（設定・認証・学習の保存先）。unlock はパスフレーズで開く（または RAM だけで使う）、mount はマウントして保存用のフォルダーを準備、status は状態の表示、close は閉じる。普段は GUI を始めるときと起動・終了時に自動で動く。
sudo jubako-exfat mount|status|unmountexFAT（プロジェクトの置き場所）をマウント・確認・取り外しする。

診断

コマンドできること
jubako-diag saveカーネル・システムログ・音声・USB-C などの診断を exFAT の logs に保存する（sudo を使う）。困ったときに、Windows から読める形で持ち帰る。
jubako-util diag io [check|before|failed|working|after]Codex・USB読み取り障害用。端末サイズ、本体起動、固定配布物とのハッシュ比較、OSイメージ読み取り、マウント、USB省電力状態、障害に絞ったカーネルログを採取。まずRAMへ保存し、exFATのdebian-live/logsへ照合付きで書き出す。sudoはカーネル閲覧とログ保存用マウントに使用。認証・会話を採取せず、修復やドライバー変更もしない。USB保存に失敗した場合は表示されたRAM内フォルダーに記録が残るが、再起動すると消える。
jubako-diag audio [before|silent|working|after]音声の診断を保存する。音が出ないときは silent、直った後は working を付けると比べやすい。
jubako-diag usb-cUSB-C の電源管理のドライバーを読み込み直してから、診断を保存する。先に USB-C の機器をすべて外す。
